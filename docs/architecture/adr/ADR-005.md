# ADR-005: Transaction / Outbox / Idempotency Boundary

Decision: Critical state transitions use a single server-authoritative transaction boundary: authenticate, authorize, load and validate policy state, enforce idempotency and expected version, finalize the evaluation revision, append mastery evidence, recompute mastery and progression, append audit and outbox events, then commit. External network or AI calls are forbidden inside this transaction.

Status: accepted
